Fullscreen on iPad

Chrome on iPad can't fullscreen web pages directly. To hide the browser bars:
  1. Tap the Share icon in Chrome
  2. Choose Add to Home Screen
  3. Open Multiview from the Home Screen
It will then launch with no browser UI. Your saved videos carry over only if you add the page with the same address.
